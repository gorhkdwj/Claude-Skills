# 분석 계획 수립

## 단계
Phase 1 — 계획

## 입력
- 이전 스킬: stakeholder-requirements-gathering
- 받는 파일: `stakeholder-requirements-gathering_report.md`

## 출력
- `analysis-planning_report.md`

## 빠른 시작

이 스킬은 분석 작업을 시작하기 전에 접근 방식을 체계적으로 구조화하는 데 도움을 줍니다.

## 필요한 컨텍스트

진행하기 전에 다음 정보가 필요합니다:

1. **분석 요청 내용**: 이 분석에서 무엇을 알고 싶은지
2. **분석 워크플로**: 분석을 어떤 순서로 진행할지
3. **소요 시간 예상**: 각 단계별 예상 시간
4. **의존 관계**: 선행되어야 할 작업이나 데이터

## 컨텍스트 수집

필요한 정보가 대화에서 빠져 있으면 다음과 같이 질문합니다:

### 분석 요청 내용이 불명확할 때:
"분석 계획을 세우려면 분석 목적을 이해해야 합니다.

다음을 알려주세요:
- 이 분석으로 어떤 질문에 답하고 싶으신가요?
- 분석 결과를 어떤 의사결정에 활용할 예정인가요?
- 참고할 수 있는 데이터나 자료가 있나요?"


### 분석 워크플로가 불명확할 때:
"분석 계획을 세우려면 전체 흐름을 파악해야 합니다.

다음을 알려주세요:
- 분석의 시작점과 끝점은 어디인가요?
- 중간에 검토나 승인이 필요한 단계가 있나요?
- 병렬로 진행할 수 있는 작업이 있나요?"


### 소요 시간이 불명확할 때:
"현실적인 일정을 잡으려면 시간 제약을 알아야 합니다.

다음을 알려주세요:
- 분석 완료 목표 시점이 언제인가요?
- 데이터 수집이나 전처리에 걸리는 시간을 알고 계신가요?
- 우선순위가 높은 단계가 있나요?"


### 일부 컨텍스트만 있을 때

일부 정보만 있는 경우:
- 제공된 정보로 가능한 범위까지 진행하고 한계를 명시합니다
- 업계 표준 기본값을 적절히 활용합니다
- 분석 진행 중 필요한 질문을 추가로 드립니다

## 워크플로

### 1단계: 컨텍스트 검증

시작 전 다음을 확인합니다:
- [ ] 필요한 컨텍스트가 모두 있거나 합리적인 기본값이 있음
- [ ] 범위와 목표가 명확함
- [ ] 기대하는 결과물이 요구사항과 일치함

### 2단계: 핵심 분석 수행

분석 계획 수립 모범 사례에 따라:

1. **초기 평가** — 제공된 컨텍스트와 데이터 검토
2. **체계적 실행** — 구조화된 방법론 적용
3. **품질 검사** — 중간 결과물 유효성 확인
4. **단계적 공유** — 논리적 체크포인트에서 발견 내용 공유

### 3단계: 결과 종합

결과를 명확하고 실행 가능한 형태로 제시합니다:
- 중요도 순으로 정렬된 핵심 발견 사항
- 뒷받침하는 근거 및 시각화 자료
- 실행 지침이 포함된 권고안
- 한계점 및 가정 사항 문서화

### 4단계: 피드백 기반 반복

초기 결과 제시 후:
- 질문에 답하고 필요한 부분을 더 깊이 파고듭니다
- 피드백을 바탕으로 분석을 정제합니다
- 추가 컨텍스트나 대안적 접근법을 제공합니다

## 컨텍스트 유효성 검사

전체 워크플로 실행 전 다음을 검증합니다:

- [ ] 의미 있는 분석을 위한 충분한 컨텍스트 확보
- [ ] 제공된 정보 간 모순 없음
- [ ] 범위가 명확하고 실현 가능함
- [ ] 기대 결과물이 명확함

## 자주 발생하는 컨텍스트 부족 상황 및 대응

**상황: 컨텍스트 없이 분석 계획 요청**
→ 대응: "분석 계획을 세워드리겠습니다! 가장 적합한 계획을 위해 [핵심 컨텍스트]가 필요합니다. [구체적인 질문]을 알려주실 수 있나요?"

**상황: 일부 컨텍스트만 제공**
→ 대응: "[확보된 컨텍스트]를 바탕으로 [가능한 범위]까지 진행하고, 추가 컨텍스트가 필요한 부분은 별도로 표시하겠습니다."

**상황: 목표가 불명확**
→ 대응: "분석이 실제로 도움이 되려면 목표를 명확히 해야 합니다. 이 분석 결과로 어떤 결정을 내릴 예정인가요? 어떤 형식이 가장 유용할까요?"

**상황: 도메인 특화 용어**
→ 대응: "용어를 정확히 이해하고 싶습니다. '[용어]'라고 하셨을 때 [해석]을 의미하시나요?"

## 심화 옵션

기본 분석 완료 후 다음을 제공할 수 있습니다:

- **심층 조사** — 특정 발견 사항을 더 파고들기
- **대안적 접근** — 다른 분석 관점 제시
- **민감도 분석(Sensitivity Analysis)** — 핵심 가정 검증
- **비교 분석(Comparative Analysis)** — 대안과의 벤치마크
- **시각화 옵션** — 결과를 표현하는 다양한 방법

원하는 방향이 있으면 말씀해 주세요!
